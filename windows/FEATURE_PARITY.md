# 원본 기능 이식 점검표

0.2.43 추가: 원본 `brainEffort`의 낮음·보통·높음을 Windows 설정과 Codex 요청에 연결했습니다. 조합의 Codex 선택·대체 경로와 텍스트 처리에도 유지하고, CLI의 읽기 전용·고정 도구·확인 정책은 그대로 적용합니다. 다른 제공자로 전환해도 선택값을 보존하며 Mac/Windows 설정 가져오기에서는 AI 연결 선택에 포함합니다. 기본 낮음을 유지하고 세 수준 외 값은 저장·실행 전에 거절합니다. 창 없는 저장/검토/복원 검사와 실제 Codex의 텍스트 응답으로 확인합니다.

0.2.40 추가: 원본 macOS `config.json`의 공통 설정을 읽고 Windows 가져오기 확인 화면에 연결했습니다. 이름·발음 보정·인사·입력 대기·단어·AI 제공자/모델·외부 목소리를 변환하며 연결은 별도 선택, Mac 장치/키/경로와 접근 권한은 보존·제외 안내를 거칩니다. 저장 전 백업과 실패 보존을 검사했고 확인 화면을 창 없이 렌더링했습니다. Windows 설정 가져오기에서 입력 증폭·이름 단서 변경도 표시합니다. Mac 언어 모델·자유 모드·기기/앱 경로의 자동 변환 등은 여전히 미지원입니다.

0.2.39 추가: 음성 과부하 때 이미 꺼낸 오래된 조각까지 폐기하고, 가득 찬 큐에 최신 소리를 보존합니다. 1.5초 넘은 입력은 큐 길이와 관계없이 버리며, 앞부분을 놓친 문장은 다음 짧은 끝점까지 실행하지 않습니다. 25초 길이 끝점과 끼어들기 초기화가 이를 해제하지 않도록 하고, 앱의 이전 이름 보정·부분 인식도 무효화합니다. 가상 입력·창 없는 App 처리·실제 한국어 모델의 합성 파일로 검사했습니다. 실제 사용자 발화·과부하 발생 빈도와 무반응 원인 검증은 남아 있습니다.

0.2.38 추가: 원본 `Butler.lastDone`/`openedURLs`의 웹페이지 열기 역동작을 연결했습니다. 새 탭 하나와 요청 주소를 확인한 경우에만 기록하며 같은 주소의 기존 탭, 변경된 주소, 중단/미확인 실행을 보호합니다. 앱·페이지·영상의 최근 열기 순서를 공통으로 기록해 ‘네가 연 창 닫아’에 사용합니다. Chrome의 단일 탭 새 창을 닫을 때 UI 스레드가 정지하는 문제를 재현한 뒤 별도 MTA 작업·8초 제한·미완료 작업 중복 차단으로 수정했습니다. 실제 Chrome·Edge 별도 프로필/로컬 페이지 및 취소·지연 응답 검사를 통과했습니다. 이미 닫은 탭의 세션 복원과 실제 로그인 사이트의 호환성은 남아 있습니다.

0.2.37 추가: 선택 가능한 인식 입력 증폭 0.25~20배와 호출 이름의 ASR 단서를 추가했습니다. 기본 1배·단서 꺼짐으로 기존 선택을 유지합니다. 원시 입력 측정·반향 보정은 그대로 사용하며 증폭은 ASR/KWS와 선택한 Whisper의 음성에 한 번만 적용합니다. 실제 한국어 모델과 파일로 만든 합성 음성에서 작은 ‘자비스’의 호출·명령 복구를 확인했지만 다른 이름·사용자 목소리·물리 마이크 문제까지 해결됐다는 의미는 아닙니다.
