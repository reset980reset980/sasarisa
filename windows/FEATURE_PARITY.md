# 원본 기능 이식 점검표

0.2.22 추가: 원본 Pro 계정 코드 발급·브라우저 승인 대기·취소·만료·Windows 자격 증명 저장·상태/사용량 조회·연결 해제, Pro 목소리 5종과 기본 음성 전환을 구현했습니다. 실제 서버의 코드 발급과 취소, 실제 WPF의 코드 표시·취소·목소리 선택·설정 저장·미연결 기본 음성 재생을 확인했습니다. 회원 계정 승인·유료 음성 생성 및 휴대폰 원격·공유는 완료되지 않았습니다.

0.2.21 추가·설치: Aside Windows CLI 제공자, 설정의 연결 상태 확인, 기존 계정·모델 사용, 10분 내 세션 이어가기, 계정·모델·설정 변경 시 새 세션, 종료·시간 초과·중지 시 해당 세션 중지 요청을 구현했습니다. 공식 서명 CLI 1.26.1023.1115에서 실제 계정과 두 차례 대화·공개 페이지 조회·중지 접수를 검사했습니다. 작업 로그가 답변에 섞이지 않도록 구분합니다. 설치본 310개 검사와 기존 설정·모델 보존을 확인했습니다. 로그인한 웹 업무와 승인 화면의 사이트별 검증은 남아 있습니다.

0.2.19~0.2.20 추가: 원본의 12회 이름 맞추기, 반복·유사 발음 학습, 명령·흔한 말 제외, 이름별 보정 저장·삭제·설정 교환, 시험 중 명령 실행 차단을 구현했습니다. 실제 WPF 창과 합성 인식 결과로 12회 완료·적용·다른 설정 저장 후 보존·재시작·삭제를 확인했습니다. 0.2.20은 기호가 있는 이름을 기호까지 비교하여 이름의 일부만으로 일치시키지 않게 보완합니다. 실제 사람의 새 발화로 이름 인식률을 검증하는 단계는 남아 있습니다.

0.2.18 추가: 기본 Windows 음성과 외부 음성의 실제 출력 크기 측정, 출력 장치에 맞춘 음성 끼어들기, 자기 답변 반향 제외, 끼어든 발화 유지·최근 0.6초 입력 복원, 자동/모든 말/호출어/끄기 설정을 구현했습니다. 개발본 294개 검사, Python 4개 검사 및 별도 시험 앱의 합성 인식 이벤트로 중단·복귀를 확인했습니다. 실제 사용자의 마이크 발화와 스피커 반향 환경 검증은 남아 있습니다.

0.2.17 추가: 실제 발화 ‘유튜브열어줘’를 ‘열어줘’ 영상 검색으로 잘못 처리하던 분류를 수정했습니다. 사이트 열기·실행의 띄어쓰기와 존댓말 변형, 명시적인 동명 곡 검색, 에스파/로파이 첫 음절 보존을 검사했습니다. 검색어가 없는 요청은 임의 검색·재생을 하지 않고 영상 이름을 묻습니다.

0.2.16 추가: 입력 프레임이 8초 이상 끊기거나 인식 프로세스가 종료되면 제한된 횟수로 다시 연결합니다. 거의 무음이면 평소 2분, 직접 호출 중 6초 후 입력 장치·음소거 확인 안내를 표시합니다. 호출 이름 없이 들은 말도 화면에서 확인할 수 있습니다. 개발본 정책 검사와 실제 프로세스 종료→재연결·사용자 중지·무음 안내를 확인했습니다. 사용자 음성 무반응의 원인 및 해결 여부는 아직 확정하지 않았습니다.

0.2.15 추가·설치: 다른 앱의 실제 마이크 사용을 감지해 자동 명령 인식 대기·복귀, 수동 호출 한 번 허용, 설정 저장을 구현했습니다. 실제 캡처 앱과 Windows 소리 설정을 이용해 대기·수동 호출·복귀·사용자가 끈 마이크 유지와 설정 해제 후 재실행을 확인했습니다. 이 검사는 사용자 발화 정확도나 보고된 음성 무반응 문제의 해결 확인을 의미하지 않습니다.

0.2.13~0.2.14 추가·설치: 카카오톡의 열린 대화방 조회, 상대·전체 문장 확인 후 초안 입력 또는 전송 요청을 연결했습니다. 실제 한국어 Windows 카카오톡에서 미전송 초안, 이모지·줄바꿈, 기존 초안 보존, 확인창 취소와 대상 변경 중단을 확인했습니다. 설치본 268개 검사와 도움말 표시를 확인했습니다. 실제 메시지 전송은 수행하지 않았으며 수신·배달 확인은 미검증입니다.

0.2.12 추가: 화면 끄기 로컬 명령·루틴·AI 도구 연결. Windows 세션 디스플레이의 꺼짐/켜짐 알림과 실제 키 입력 후 복귀를 확인했습니다. 실행 직전 중지 및 AI 확인창 취소 시 화면 끄기를 전달하지 않았습니다.

0.2.10~0.2.11 추가: Claude Windows Code의 기존 세션 조회·전환·확인 후 전달. 로컬·클라우드 세션과 새 세션 시작 화면에서 검색을 검증했습니다. 취소 또는 승인 중 초안 변경 시 전송을 중단합니다. 공백이 있는 호출 이름의 마이크 종료 문제도 수정했습니다.

0.2.9 추가: 외부 API/Ollama 직접 도구 호출과 이미지 결과 전달. Claude/Codex와 같은 37개 도구, 단계별 승인·취소·대상 검사, 최대 12회 반복을 연결했습니다. 8개 제공자 규약 검사와 실제 로컬 HTTP 시험 서버를 통한 입력·이미지 전송·취소를 확인했습니다. 실제 제공자 계정과 로컬 AI 모델 품질은 별도 검증이 필요합니다.

0.2.8 추가: 단일 키 전달을 Ctrl/Alt/Shift/Win 복합 조합, 기능·이동·선택·편집·기호 키로 확장했습니다. 편집 확인창의 대상 초점 유지와 부분 입력 후 눌림 해제를 구현했습니다. 음성 인식 정확도 튜닝은 별도 작업입니다.

0.2.7 추가: 기존 앱 창 조회·선택과 `front` 현재 작업 창 확인. 같은 앱의 여러 창과 최소화된 창을 구분하고, 선택한 창에 후속 입력을 연결합니다. 실제 A 창에서 최소화된 B 창으로 전환한 뒤 B의 두 번째 입력칸에만 글을 추가하는 흐름을 확인했습니다. 브라우저·Store 앱·다른 가상 데스크톱의 현장 검사는 남아 있습니다.

0.2.6 추가: 조회한 입력칸의 커서에 글 추가 또는 선택 부분만 교체하는 `insert_field`. 나머지 글 보존, 커서·선택 영역 변경 감지, 한글·이모지 입력과 결과 확인을 구현했습니다. 실제 WPF 시험 창에서 삽입·선택 교체·확인 중 커서 이동 시 무입력을 확인했습니다. 앱이 접근성 커서 정보를 제공해야 하며 다양한 문서 앱·브라우저의 호환성 검사는 남아 있습니다.

0.2.5 추가: Claude/Codex의 대상 창 이미지 읽기와 좌표 클릭, 클릭 위치 미리보기, 창·화면 변경 감지. 실제 WPF 그림을 읽고 파란 원을 누르는 흐름 및 확인 중 바뀐 도형에 대한 클릭 차단을 확인했습니다. 당시 이미지 입력은 Claude/Codex MCP에 연결했으며, 0.2.9에서 외부 API/Ollama 연결도 추가했습니다. 실제 브라우저·추가 앱 호환성 검증은 남아 있습니다.
