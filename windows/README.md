# 자비스 · Windows

Sasarisa를 바탕으로 만든 Windows 데스크톱 음성 비서입니다. macOS Swift 앱은 유지하고 Windows용 WPF 앱과 Python 음성 프로세스를 별도로 구현했습니다. 이 버전은 원본의 모든 외부 연동과 동작을 1:1로 재현한 버전은 아닙니다.

Windows 개발은 `windows` 브랜치에서 진행합니다. 원본 기능의 전체 현황은 [이식 점검표](FEATURE_PARITY.md)를 확인하세요. 보고된 마이크 무반응 문제의 해결과 실제 회원 계정·휴대폰 연결 검증은 남아 있습니다.

## 실행

0.2.25에서 **무료 휴대폰 연결**을 추가했습니다. 왼쪽 메뉴 → `휴대폰 연결 · 무료` → `연결 켜기`를 누릅니다. PC와 같은 공유기에 연결한 휴대폰 브라우저에서 표시된 주소를 열고 8자리 코드를 입력하면 PC에 명령을 보내고 결과를 받을 수 있습니다. 휴대폰 앱 설치나 원본 Pro 계정은 필요하지 않습니다. PC의 AI 제공자 요금은 그대로 적용됩니다.

PC가 유선으로 연결돼 있어도 같은 공유기면 됩니다. 연결 코드는 10분, 연결된 세션은 최대 8시간 유효하며 4대까지 연결할 수 있습니다. `연결 끄기` 또는 `새 코드 · 연결 초기화`로 모든 휴대폰을 해제하고 진행 중인 휴대폰 요청을 취소합니다. 앱을 다시 실행하면 자동으로 켜지지 않습니다. 폰 키보드의 음성 입력으로 명령을 작성할 수 있습니다. 휴대폰 웹 자체의 녹음·음성 인식과 외부 인터넷 접속 기능은 포함하지 않습니다.

신뢰하는 집·사무실 네트워크에서만 켜세요. IPv4 로컬 HTTP 연결(기본 포트 17845)이며 선택한 인터페이스의 같은 서브넷만 받습니다. Windows 방화벽이 접근을 물으면 해당 앱의 개인 네트워크 접근을 허용해야 합니다. 방화벽이나 공유기 포트포워딩 설정은 자동으로 바꾸지 않습니다. 접속이 안 되면 게스트 와이파이·모바일 데이터·공유기의 기기 간 통신 차단을 확인하세요. 코드와 토큰은 메모리에서만 보관하며 휴대폰 토큰은 브라우저의 해당 탭 세션에 저장합니다. `phone-receipts.json`은 중복 실행 방지를 위한 요청 ID·결과 기록이며, 기록 손상이나 5,000건 도달 시 새 실행을 중단합니다. 네트워크 단절 후에는 같은 요청 ID로 결과를 확인하며 자동 중복 실행하지 않습니다. PC 확인이 필요한 동작은 기존 원격 실행 제한을 유지합니다.

휴대폰의 `소스 코드` 링크에서 설치본과 함께 제공되는 해당 버전 소스 압축 파일을 받을 수 있습니다. 로컬 서버는 ASP.NET Core/Kestrel을 사용하며 런타임과 라이선스 고지를 설치본에 포함합니다. 개발 검증은 `--self-test --phone-only`, 실제 앱 연동은 별도 `VOICE_ASSISTANT_HOME`에서 `--self-test --phone-app-only`로 실행합니다. `--phone-ui-preview`는 별도 프로필에서만 켤 수 있는 루프백 UI 확인 모드이며 시각 확인만 실행합니다.

0.2.24에서 **다 같이 키우기**를 추가했습니다. 설정 → 기억과 실행 방법 → 다 같이 키우기에서 `끄기`, `혼자 키우기 · 공유 명령만 받기`, `다 같이 키우기 · 짧은 명령 공유하고 받기`를 고르고 설정을 저장합니다. 기본값은 꺼짐이며 설정 가져오기로 공유 선택이 바뀌지 않습니다. 공유를 켠 뒤 이 PC에서 AI에게 배운 말 중 허용된 명령 단어로만 된 2~24자 표현과 소리·재생·기본 앱 등의 단일 명령만 전송 후보가 됩니다. 임의 단어, 검색어, 등록 앱, 타이머 내용, 답변, 음성, 화면, 기억과 휴대폰 요청은 전송하지 않습니다. 원본 서비스 `maker.buffm.com`에 무작위 설치 식별자로 전송하며 계정 키를 사용하지 않습니다.

공유 목록은 약 하루에 한 번 받고 허용된 명령인지 다시 검사합니다. 기본 명령과 직접 배운 말이 우선이며, 공유 표현으로 실행한 직후 30초 안에 `아니` 또는 `틀렸어`라고 하면 해당 표현/명령 조합을 이 PC에서 제외합니다. 이미 실행한 동작을 취소하는 뜻은 아닙니다. 끄면 통신과 공유 명령 사용을 중지하며 늦게 도착한 응답을 적용하지 않습니다. 기록은 `grow-state.json`에 보관합니다. 서버로 이미 보낸 항목의 삭제 API는 제공하지 않습니다. 공개 목록 수신은 실제 서비스로 검사했고, 기여 POST는 모의 서버에서 검사했습니다. 사용자 표현을 실제 공유하지 않았으며 서버의 집계·채택 결과는 미검증입니다. 원본보다 기여 어휘를 좁게 제한하고, 기존 학습 기록을 일괄 전송하지 않습니다.

0.2.23에서 **휴대폰 원격 명령 수신과 결과 회신**을 앱에 연결했습니다. 설정 → 목소리와 출력 장치 → `휴대폰에서 이 PC에 명령 보내기`를 체크하고 설정을 저장합니다. 기본값은 꺼짐이며, Pro 계정 연결과 서버의 원격 이용 권한이 필요합니다. PC 앱이 실행 중일 때 명령과 답변을 Sasarisa 서버로 주고받으며, 수신 포트나 방화벽 예외를 만들지 않습니다. PC에서 새 명령을 입력하면 진행 중인 원격 요청을 중지합니다. 휴대폰에서 `중지`를 보내도 원격 요청을 취소할 수 있습니다.

PC 확인이 필요한 동작은 휴대폰에 미실행 사유를 돌려줍니다. 원본의 자유 모드, Aside를 통한 원격 웹 작업과 실제 회원 계정·휴대폰 왕복 검증은 남아 있습니다. 요청 ID와 짧은 결과는 사용자 데이터 폴더의 `remote-receipts.json`에 저장하여 재전송 때 같은 동작을 반복하지 않습니다. 처리 기록이 손상되거나 저장되지 않거나 5,000건에 도달하면 원격 실행을 멈추고 안내합니다. 설정 가져오기는 기존 원격 켜짐/꺼짐을 바꾸지 않습니다. 계정 창에서 상태를 다시 확인하거나 연결을 바꾼 뒤 닫으면 원격 연결도 다시 확인합니다.

0.2.22에서 **Sasarisa Pro 계정과 음성**을 추가했습니다. 설정 → 목소리와 출력 장치 → `Pro 계정 연결·사용량`에서 코드를 받은 뒤 브라우저에서 연결을 승인합니다. 목소리 제공자로 `Sasarisa Pro`를 선택하면 한국어 3종·영어 2종 목소리를 사용할 수 있습니다. 기기 키는 Windows 자격 증명에 별도로 보관하며 설정 파일·내보내기에 넣지 않습니다. 실제 서버의 코드 발급·취소와 계정이 없을 때 기본 음성으로 전환되는 동작을 확인했습니다. 회원 계정 승인·유료 음성 생성 품질·휴대폰 원격 기능은 별도 검증/구현이 남아 있습니다.

Pro 한도 초과 또는 서버 과부하 응답은 한 시간 동안 기본 목소리로 전환합니다. 계정 창에서 `상태 새로 확인`하면 다시 시도할 수 있습니다. `이 PC 연결 해제`는 즉시 이 PC의 키를 지우고 서버에도 해제를 요청합니다. 서버 확인에 실패하면 별도 안내가 표시됩니다. 계정 연결을 취소하거나 창을 닫으면 이 PC의 승인 대기가 끝나므로 승인 페이지도 닫아 주세요.

0.2.21에서 **Aside Windows CLI 연결**을 추가했습니다. 설정의 AI 제공자를 `Aside · 브라우저 작업`으로 고르고 연결 상태를 확인한 뒤 저장하세요. 질문·웹 작업은 Aside에서, 시각·타이머·앱 실행 같은 기본 명령은 Windows 비서에서 처리합니다. 같은 계정·모델로 10분 안에 이어 말하면 같은 Aside 세션을 사용합니다. 중지 버튼은 해당 세션에도 중지를 요청하며, 접수 여부를 안내합니다. 웹 작업의 권한 확인은 Aside 화면에서 진행합니다.

Aside CLI는 [공식 Windows 설치·로그인 안내](https://docs.aside.com/help/developers)의 서명된 설치 프로그램으로 설치합니다. 기본 경로 `%LOCALAPPDATA%\Aside\CLI\current\aside.exe`와 PATH에서 찾으며, 별도 설치 위치는 `SASARISA_ASIDE_BIN`에 실행 파일의 절대 경로를 지정할 수 있습니다. 계정 비밀번호·토큰은 이 앱의 설정이나 내보내기 파일로 복사하지 않습니다. CLI 1.26.1023.1115의 실제 계정 연결·후속 대화·공개 페이지 열기와 제목 확인·세션 중지 접수를 검사했습니다. 로그인한 웹사이트의 업무와 권한 흐름은 별도 확인이 필요합니다.

0.2.19~0.2.20에서 **내 목소리로 이름 맞추기**를 추가했습니다. 설정에서 이름과 입력 마이크를 고른 뒤 이름 아래 버튼을 누르세요. 이름만 8번, 짧은 명령과 함께 4번 읽고 매번 ‘다 말했어요’를 누릅니다. 시험 문장은 실행하지 않으며 읽을 수 없는 무음 회차는 제외합니다. 결과를 확인한 뒤 적용하면 이름별 보정 발음을 저장하고, 원래 켜 두었던 마이크는 다시 듣습니다. 시험 글에서 계산한 감지 비율이므로 저장 후 새 발화로 확인해야 합니다. 이름 보정 창에서 기존 보정을 지울 수 있고, 설정 내보내기·가져오기에도 포함됩니다. 음성 파일은 저장하지 않습니다. 기호가 있는 이름도 기호를 포함해 비교합니다.

0.2.18에서 **답변 중 음성 끼어들기**를 추가했습니다. 마이크를 켜 둔 상태에서 자동 모드는 헤드셋에서는 말을 감지하고, 스피커에서는 호출어·중지 말 또는 반향보다 큰 목소리를 확인합니다. 설정에서 모든 말·호출어만·끄기로 바꿀 수 있습니다. 누르는 동안 듣기 모드에서는 단축키를 사용하세요. 실제 마이크에서 소리가 들어와야 하며, 입력이 거의 무음인 문제를 해결했다는 뜻은 아닙니다.

0.2.17에서 **‘유튜브 열어줘’, ‘유튜브 실행해줘’가 홈을 열도록** 수정했습니다. ‘열어줘’라는 영상을 찾으려면 ‘유튜브에서 열어줘 검색해’처럼 영상 검색임을 말하세요. 붙여 인식된 ‘에스파’, ‘로파이’의 첫 음절도 유지합니다.

0.2.16부터 **마이크 입력이 끊기면 자동으로 다시 연결**합니다. 반복 실패하면 멈추고 안내하며 ‘듣기 중지’로 재연결도 취소할 수 있습니다. 거의 무음인 상태가 계속되면 입력 장치와 헤드셋 음소거 확인 안내를 표시합니다. ‘지금 말하기’ 중에는 6초, 평소에는 2분이 기준입니다. 이름이 감지되지 않아도 인식된 말은 화면에서 확인할 수 있습니다. 이 안내가 음소거나 기기 고장을 확정하는 것은 아닙니다.

0.2.15부터 **다른 앱이 마이크를 사용하면 자동 듣기를 대기**합니다. 통화·녹음이 끝나면 켜 둔 듣기만 다시 시작합니다. 대기 중에도 단축키나 ‘지금 말하기’로 한 번 말할 수 있습니다. 설정의 ‘다른 앱이 마이크를 사용하면 자동 듣기 대기’에서 끌 수 있습니다. Windows 소리 설정의 마이크 시험 화면도 마이크를 사용할 수 있습니다. 이 기능은 명령 인식을 잠시 멈추며 마이크 권한이나 다른 앱의 녹음을 변경하지 않습니다.

0.2.13에서는 **카카오톡 대화방을 먼저 연 뒤 ‘카톡 대화방 목록’, ‘카톡에 안녕하세요라고 입력해줘’, ‘카톡 초안 전송’**을 사용할 수 있습니다. 초안과 전송을 구분하고 대화방 이름·전체 문장을 확인받습니다. 기존 초안은 덮어쓰지 않고 확인 중 창이나 내용이 바뀌면 중단합니다. 실제 초안 입력·취소는 검사했으며 메시지 전송과 상대 수신은 아직 현장 검증하지 않았습니다.

**‘화면 꺼’, ‘모니터 꺼줘’**로 모니터를 끌 수 있습니다. 마우스를 움직이거나 키를 누르면 다시 켜집니다. 루틴에 넣을 수 있고 AI를 통한 실행은 확인창을 거칩니다.

0.2.10에서는 **Claude Windows 앱의 기존 Code 세션을 조회·전환하고 작업을 전달**할 수 있습니다. 예: `Claude의 Git Mac 소스 확인 세션으로 전환해 줘`. 작업을 전달할 때는 프로젝트·세션 이름과 본문을 확인한 뒤 실행합니다. 기존 초안이 있거나 확인 중 세션·초안이 바뀌면 보내지 않습니다. 한국어 Claude 앱의 로컬·클라우드 세션 화면을 지원합니다. **0.2.11부터는 Code의 ‘새 세션’ 시작 화면에서도 기존 세션을 바로 찾을 수 있습니다.** 작업 접수 이후의 응답·권한 요청은 Claude에서 확인합니다. 공백이 포함된 호출 이름 때문에 마이크가 종료되던 오류도 수정했습니다.

0.2.9에서는 **외부 API와 Ollama도 Windows 도구를 직접 호출**합니다. 선택한 창의 입력칸 조회·편집, 단축키, 이미지 확인과 좌표 클릭을 단계별 실행 결과에 따라 이어갑니다. 글 입력·이미지 전송·클릭에는 기존 확인창이 적용되며 취소하면 후속 실행을 멈춥니다. 함수 호출을 지원하는 모델이 필요하고, 화면을 보고 판단하는 작업에는 이미지 입력도 지원해야 합니다. 실제 로컬 시험 서버에서 입력·이미지 전달·취소를 확인했으며, 유료 계정과 실제 Ollama 모델의 응답 품질은 아직 검증하지 않았습니다.

0.2.8에서는 **커서 이동·글 선택·삭제와 복합 단축키**를 사용할 수 있습니다. 예: `현재 줄을 Home, Shift+End, Backspace 순서로 지워 줘`. Ctrl/Alt/Shift/Win과 영문자·숫자·F1~F24, 방향키·Home/End/PageUp/PageDown·Insert/Delete 등을 조합합니다. `cmd`는 Windows Ctrl, `option`은 Alt로 해석하며 `delete`는 커서 오른쪽, `backspace`는 왼쪽을 지웁니다. `+` 기호는 `plus`로 지정합니다.

편집·앱 단축키는 실행 내용을 확인한 뒤 전달합니다. 확인 중 작업 창이나 초점 항목이 바뀌거나 키가 이미 눌려 있으면 멈춥니다. 같은 입력칸 안의 커서 이동까지 감지하는 기능은 아니며, 정확한 부분 교체에는 `insert_field`를 사용합니다. 비서의 말하기·중지 단축키, Win+R, Ctrl+Alt+Delete는 전달하지 않습니다. 단축키로 다른 창이 열리면 후속 작업 전에 창 목록에서 대상을 다시 선택합니다. 앱마다 단축키의 의미와 지원 여부는 다를 수 있습니다.

0.2.7에서는 **열려 있는 다른 앱 창으로 옮겨 작업을 이어갈 수 있습니다.** 예: `열린 메모장 중 회의록 창으로 전환한 뒤 두 번째 입력칸에 내용을 추가해 줘`. AI가 앱 이름과 창 제목을 조회해 정확한 창을 선택하고, 최소화된 창은 복원합니다. 같은 앱의 여러 창을 제목으로 구분하며, 전환 후 입력·버튼 조작은 선택한 창에 연결됩니다. 사용자가 중간에 다른 창으로 옮기거나 조회한 창의 앱·제목이 바뀌면 멈춥니다. 다른 가상 데스크톱의 숨겨진 창과 보호된 앱은 선택 목록에서 제외합니다.

0.2.6에서는 특정 입력칸의 **커서 위치에 글 추가**와 **선택한 부분만 교체**를 지원합니다. 예: `두 번째 메시지 칸의 현재 커서에 안녕하세요를 추가해 줘`. 실행 전 대상과 내용을 확인하고, 기다리는 동안 글·커서·선택 영역이 바뀌면 입력하지 않습니다. 이 동작은 나머지 글을 보존하며 입력 후 결과와 커서도 확인합니다. 앱이 접근성 정보로 커서 위치를 제공해야 하고, 입력 전후 전체 글은 각각 6,000자 이내여야 합니다.

0.2.5에서는 Claude Code 또는 Codex를 연결하면 선택한 창의 그림을 보고 위치를 누를 수 있습니다. 예: `현재 창의 파란 원 가운데를 눌러 줘`. 이미지 전송 전 대상 창과 제공자를 확인하고, 클릭 전에는 빨간 표시로 위치를 보여 줍니다. 확인 중 화면이 바뀌면 멈춥니다. 일부 영상·GPU·보호된 창은 이미지 읽기를 지원하지 않을 수 있습니다.

바탕화면 **자비스 Windows** 바로가기로 실행합니다. 기본 호출 이름은 **자비스**이며 설정에서 바꿀 수 있습니다.

Windows 10/11 x64용 설치 파일은 `windows/dist/Sasarisa-Windows-0.2.24-x64.msi`입니다. 현재 사용자의 계정에 설치하며 Python과 .NET 실행 환경을 포함합니다. 별도 개발 도구는 필요하지 않습니다. 기본 위치는 `%LOCALAPPDATA%\SasarisaWindows`이고 시작 메뉴와 바탕화면에 바로가기를 만듭니다. 유튜브 창에는 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)이 필요합니다.

처음 설정의 **한국어 모델 받기 / 복구**에서 약 133 MB를 받습니다. 진행률·취소·재시도를 지원하며 모든 파일의 크기와 SHA-256을 확인한 뒤 적용합니다. 이미 받은 모델은 인터넷 없이 사용할 수 있습니다. 마이크는 **듣기 시작**을 누를 때 켜집니다. AI 대화는 선택한 제공자의 로그인·키 또는 로컬 모델이 별도로 필요합니다.

더 높은 버전의 MSI를 실행하면 기존 앱을 종료하고 앱 파일과 설정·기억·등록 앱·타이머를 `%LOCALAPPDATA%\VoiceAssistantWindows\install-backups`에 ZIP으로 보관한 뒤 업데이트합니다. 백업에 API 키나 다운로드한 음성 모델은 넣지 않습니다. ZIP의 `app` 폴더는 이전 실행 파일, `user-data`는 당시 설정이며 `backup-info.json`에 원래 설치 위치와 누락 파일을 기록합니다. 복원할 때에는 비서를 종료한 뒤 별도 폴더에 풀어 내용을 확인하세요. Windows의 **설치된 앱 → 자비스 Windows → 제거**는 실행 파일과 바로가기를 제거하고 사용자 설정·모델·백업은 남깁니다.

설치 폴더의 `Sasarisa-Windows-Source.zip`에 대응하는 소스와 빌드 스크립트를 포함합니다. 코드 서명된 공개 릴리스는 아직 제공하지 않으며, 이 패키지는 로컬 Windows 포트 시험 빌드입니다.

새 PC에서 소스 설치:

1. Windows 10/11 x64, Python 3.11 또는 3.12, .NET 10 SDK와 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)을 준비합니다.
2. Windows 브랜치를 내려받아 다음을 실행합니다. 최초 한국어 모델 다운로드는 약 420 MB입니다.

```powershell
git clone -b windows https://github.com/reset980reset980/sasarisa.git
cd sasarisa\windows
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\run.cmd
```

`setup.ps1`은 가상환경·모델 준비, 의존성 검사, Release 빌드와 개발용 바탕화면 바로가기 생성을 수행합니다. 소스 실행은 `windows\run.cmd`를 사용합니다. 소스 폴더를 옮기면 `install-shortcut.ps1`을 다시 실행하세요. 설치본의 바로가기와 이름이 같으므로 개발용 바로가기를 만들면 설치본 바로가기를 대체합니다.

설치 패키지 빌드: 개발 환경 준비 후 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build-installer.ps1 -Version 0.2.24`. 공식 Python 임베디드 배포의 해시·게시자를 확인하고 고정된 wheel 해시를 검사합니다. WiX 4.0.6은 프로젝트 NuGet 의존성으로 복원합니다. 결과는 `dist`에 MSI·SHA-256·빌드 정보로 기록합니다.

## 처음 사용하기

- 첫 실행 시 이름·사용자 호칭·AI·목소리·마이크·알림 위치를 정하는 안내가 열립니다. 음성 모델 파일과 입력 장치 목록도 확인합니다. 나중에 **사용 방법 → 처음 설정 다시 열기** 또는 트레이의 **처음 설정**으로 다시 열 수 있습니다. AI의 실제 로그인/응답 여부는 연결 시험이나 대화에서 확인하세요.
- 마이크는 처음에 꺼져 있습니다. **듣기 시작**을 누르고 ‘자비스’라고 부릅니다.
- 기본 말하기 키는 **Ctrl+Shift+Space**, 중지 키는 **Ctrl+Alt+Backspace**입니다. **설정 → 단축키와 알림 위치**에서 입력 칸을 누르고 원하는 키 조합을 누른 뒤 저장하세요. 같은 조합이나 다른 앱이 이미 등록한 조합은 저장하지 않습니다. 시작 시 충돌하면 말하기 **Ctrl+Alt+F9**, 중지 **Ctrl+Alt+F10**을 대체 키로 시도하고 실제 적용된 키를 표시합니다.
- 이름 인식이 어려우면 **설정 → 호출 방식 → 단축키로만 호출**을 선택합니다.
- **키를 누르는 동안만 듣기**를 선택하면 설정한 말하기 단축키를 누른 채 말하고 키를 놓을 때 처리합니다. 대기 중에는 음성 모델로 문장을 인식하지 않으며, 최대 30초까지 말할 수 있습니다. 이 모드에서는 말하기 단축키를 끌 수 없습니다. ‘말하기 안내’ 버튼은 단축키 사용법을 표시합니다. 연속 받아쓰기는 다른 호출 방식을 사용하세요.
- 텍스트 입력도 같은 명령을 실행합니다. Enter로 보내고 Shift+Enter로 줄을 바꿉니다.
- AI는 실행 결과를 확인하면서 다음 동작을 이어갑니다. 예: ‘타이머 목록을 확인해서 이름에 회의가 들어간 것만 취소해 줘’, ‘선택한 창의 문서를 읽어서 둘째 줄을 알려줘’. 진행 단계가 대화에 표시되고 최대 12회 안에 끝내지 못하면 중단합니다. 글 입력·버튼 누르기는 실행 내용을 확인합니다. 작업 도중 다른 창을 선택하면 이전 대상에 대한 작업을 멈춥니다.
- 조건이나 조회 결과에 따라 달라지는 요청은 고정 명령으로 자동 학습하지 않습니다. 새로 열린 창을 자동 식별하지 못하면 열린 창/탭 목록을 다시 조회해 대상을 선택할 수 있습니다. 같은 이름의 창이 여러 개라면 원하는 문서나 창 제목을 함께 알려 주세요.
- **중지** 또는 **Ctrl+Alt+Backspace**로 진행 중인 요청과 음성 출력을 멈춥니다. ‘그만’ 음성 명령은 듣는 동안 사용할 수 있습니다. 답변 음성이 스스로 재인식되는 것을 막기 위해 처리·음성 출력 중에는 음성 인식을 잠시 멈춥니다.
- X는 창을 트레이로 숨깁니다. 다시 실행하면 기존 창을 표시합니다. **앱 종료**는 마이크와 도우미 프로세스까지 종료합니다.
- **설정 → 목소리와 출력 장치**에서 설치된 Windows 음성, 스피커/헤드셋, 읽기 속도(-5~5), 답변 음량(0~100)을 선택합니다. ‘목소리 들어보기’는 저장 전 선택한 값으로 시험 출력합니다. 답변 음량은 Windows 전체 음량을 바꾸지 않습니다.
- 0.2.3의 **음성 제공자 설정**에서 Windows 기본 음성 외에 ElevenLabs, OpenAI, Azure Speech, 사용자 음성 서버를 선택할 수 있습니다. 제공자·목소리·모델·속도를 정하고 ‘목소리 시험’으로 확인한 뒤 ‘이 설정 사용’과 메인 화면의 ‘설정 저장’을 누릅니다. 외부 제공자에는 읽을 문장이 전달되며 서비스 사용료가 발생할 수 있습니다. API 키는 AI 대화용 키와 별개로 Windows 자격 증명 관리자에 저장하고 설정 내보내기에는 포함하지 않습니다. 음성 생성·재생을 취소할 수 있으며, ‘외부 음성 실패 시 Windows 기본 목소리로 읽기’를 켜면 오류를 표시하고 기본 목소리로 읽습니다. 유료 제공자는 요청 형식을 검사했으며 실제 계정으로 생성 품질과 권한을 확인하는 작업은 남아 있습니다.
- 외부 음성 설정: ElevenLabs는 Voice ID와 API 키(속도 0.7~1.2), Azure Speech는 리소스 지역과 키(기본 `ko-KR-SunHiNeural`, 속도 0.5~2), OpenAI는 별도 음성 API 키와 Speech API 모델(기본 `gpt-4o-mini-tts`, `alloy`)을 사용합니다. OpenAI의 해당 Speech API 모델은 공식 문서상 2027-01-06 종료 예정이므로 서비스 이용 전 [현재 지원 안내](https://developers.openai.com/api/docs/guides/text-to-speech)를 확인하세요. Realtime 모델은 이 설정의 대체 모델로 사용할 수 없습니다. 사용자 서버는 HTTPS 또는 루프백 HTTP의 전체 주소에 `{ "text": "읽을 문장", "voice": "목소리", "language": "ko" }`를 POST하고 WAV 또는 MP3를 받아 재생합니다. 선택 API 키는 Bearer 헤더로 보내며 자동 리디렉션은 따르지 않습니다.
- 알림은 가운데·아래 가운데·오른쪽 아래·왼쪽 아래·위 가운데 중 선택하고 모니터를 지정할 수 있습니다. 선택한 모니터가 연결되지 않았다면 기본 화면을 사용합니다. ‘듣기 대기 중에도 작은 표시 유지’를 켜면 작은 버튼으로 바로 말하기를 시작할 수 있습니다. 마이크를 끄면 작은 표시도 숨깁니다.
- **설정 → 호칭과 인사**에서 사용자 호칭, 호출 문장, 인사말, 제목·부제, 화면 종류를 정합니다. `{user}`와 `{assistant}`는 호칭과 비서 이름으로 바뀝니다. 기본 호출은 ‘안녕’, ‘나 왔어’, ‘아빠 왔어’, ‘일어나’ 등이며, 호출 문장을 직접 지정하면 기본 문장을 대체합니다. 원형 애니메이션·차분한 화면·작은 알림을 선택할 수 있고, 실제 인사 명령에서는 지정한 웹사이트와 앱을 합쳐 최대 8개 엽니다. 미리 보기에서는 앱과 웹사이트를 열지 않습니다.

## 기능과 예시

0.2.3의 받아쓰기에는 편집 명령도 연결되어 있습니다. `받아적어 내일 만나요`로 음성 인식 없이 같은 입력 경로를 사용할 수 있습니다. 연속 받아쓰기 중 `줄바꿈·엔터·보내·전송`은 Enter, `지워·취소·되돌려`는 현재 문서의 Ctrl+Z, `그만·끝`은 받아쓰기 종료입니다. `내일 만나요 보내`처럼 끝에 띄어 붙인 `엔터·보내·enter·send`는 문장 입력 후 Enter를 누릅니다. Enter와 여러 줄 입력은 내용을 확인한 뒤 실행하며, 거절하면 문장도 입력하지 않습니다. 실행 취소 단위는 문서 앱이 정합니다. 메모장에서 문장 입력/되돌리기/줄바꿈/확인 거절/대상 창 변경 중단을 검증했습니다.

0.2.3에는 아래 브라우저 기능을 추가했습니다. 모의 브라우저와 AI 계획 연결은 검사했으며, 실제 Chrome/Edge와 로그인된 네이버 메일에서의 현장 검증은 남아 있습니다.

0.2.4에는 AI가 작업할 창의 버튼·입력칸 목록을 조회하고, 같은 이름의 항목을 부모 영역과 조회 ID로 구분하는 기능을 추가했습니다. 예를 들어 `현재 창의 두 번째 영역 메시지 입력칸 전체를 안녕하세요로 바꿔 줘`처럼 요청할 수 있습니다. 입력칸 전체 교체와 항목 누르기는 대상과 내용을 확인한 뒤 실행합니다. 확인을 기다리는 사이 창·항목·기존 글이 바뀌면 멈추며, 암호·읽기 전용 칸은 편집 목록에 포함하지 않습니다. 전체 교체는 기존 내용과 새 글이 각각 6,000자 이내일 때 지원합니다. Claude/Codex는 별도 MCP 연결로 이 앱의 동작을 직접 호출하며, 실행 결과를 확인해 다음 동작을 결정합니다. 중지 단축키 Ctrl+Alt+Backspace는 확인 대기 중인 창도 닫습니다. 원본 도구별 차이와 남은 연결 작업은 [TOOLS_PARITY.md](TOOLS_PARITY.md)를 참고하세요.

- ‘쿠팡에 키보드 검색해’ 다음 ‘마우스 검색해’처럼 말하면 120초 동안 직전 검색 사이트를 사용합니다. 사이트를 명시하면 그 사이트로 전환합니다. 네이버 쇼핑·아마존 검색과 메일 페이지 열기도 지원합니다.
- ‘탭 목록’, ‘전체 탭 목록’, ‘탭 목록 2페이지’, ‘두 번째 탭 열어’, ‘세 번째 탭 닫아’, ‘네이버 탭 닫아’. 목록은 6개씩 표시하고 탭 주소를 확인할 때 잠시 탭을 전환한 뒤 원래 선택으로 돌아갑니다.
- 사이트별 닫기는 선택한 브라우저 창에서 먼저 찾고, 그 창에 없으면 다른 브라우저 창에서도 찾습니다. 정확한 도메인 경계를 검사하며 유튜브 스튜디오는 유튜브 탭 닫기에서 제외합니다. 브라우저의 저장·나가기 확인창은 자동으로 승인하지 않습니다.

관리 화면에서는 기억 내용, 루틴 이름/동작, 배운 호출 문장/답변/동작을 편집합니다. ‘추가할 명령’에 ‘메모장 열어’, ‘3분 타이머’ 또는 웹 주소를 입력하고 ‘동작 추가’를 누르세요. 루틴·배운 실행 방법은 각각 동작 1~8개를 저장하며 편집만으로 실행하지 않습니다. 마지막 저장·삭제는 같은 창에서 복원할 수 있습니다. 관리 중에는 듣기를 멈추고 창을 닫으면 이전 듣기 상태로 돌아갑니다. 손상된 개인화 파일은 경고하고 덮어쓰지 않습니다.

‘자주 쓰는 단어와 받아쓰기’에서 이름·전문 용어를 한 줄에 하나, 최대 150개 등록할 수 있습니다. 저장 후 다음 인식부터 한국어 모델의 단어 힌트로 사용합니다. 지원하지 않는 문자는 제외 안내가 표시됩니다. 이 설정은 인식 후보와 처리 속도에 영향을 주므로 정확도 향상을 보장하지 않습니다. 기본 목록은 비어 있습니다.

말버릇 제거는 ‘음’, ‘으음’처럼 단어 전체가 일치하는 부분만 제거하고 ‘음식’, ‘음악’은 보존합니다. ‘선택한 AI로 받아쓰기 다듬기’는 기본적으로 꺼져 있습니다. 켜면 받아쓴 글과 등록 단어 일부를 설정한 AI로 보내 맞춤법·띄어쓰기·숫자 표기를 다듬습니다. 6초 초과·연결 실패·잘못된 응답이면 기본 정리 결과를 사용하고, 사용자가 취소하면 입력하지 않습니다. 설정의 ‘다듬기 시험’은 저장 전 단어 설정과 저장된 AI 연결을 사용하며 다른 앱에는 입력하지 않습니다. 실제 받아쓰기 처리 중 다른 대상 창으로 바뀌면 입력을 중단하고 대화 기록에 글을 남깁니다.

유튜브 검색 목록은 최대 10개이며 1시간 동안 선택할 수 있습니다. 영상은 전용 WebView2 창 한 개에서 교체하여 소리가 겹치지 않습니다. 사용자의 다른 브라우저 탭은 닫지 않습니다. 자동 재생이 차단되면 영상의 재생 버튼을 누르세요. 전용 창은 별도 로컬 프로필을 사용하며 로그인은 지원하지 않습니다. 로그인 등이 필요한 영상은 ‘브라우저에서 열기’를 이용하세요. 유튜브 페이지 구조가 바뀌어 검색 목록을 읽지 못하면 검색 페이지를 엽니다.

글 선택/화면 읽기는 Windows UI Automation을 지원하는 앱에서 동작합니다. 암호 입력란과 터미널·시스템 관리 앱 등 보호 대상에는 자동 입력하지 않습니다. 관리자 권한으로 실행된 다른 앱에는 일반 권한 비서가 입력할 수 없습니다. 카카오톡은 일반 입력 대신 전용 대화방 확인 기능을 사용합니다. 현재 한국어 26.9.0.5337을 검사했으며, 다른 버전에서 빈 입력 안내를 초안으로 읽는 경우 덮어쓰지 않고 중단합니다. 닫힌 대화방을 검색하거나 연락처를 추측하지 않습니다. 이름을 생략하려면 사용할 대화방 하나만 열고, 이름을 지정할 때는 창 제목 그대로 요청하세요.

타이머는 디스크에 저장되며 앱을 다시 켜면 복원됩니다. PC나 앱이 꺼져 있을 때 알림을 재생하지는 못하며, 지나간 알림은 다음 실행 시 표시합니다.

동작 기록은 현재 앱 실행 중 최근 20개를 보관하고 ‘방금 뭐했어’로 최근 5개를 표시합니다. ‘되돌려’는 아직 되돌리지 않은 직전 동작 하나에 적용합니다. 기억 추가·루틴 저장/삭제도 변경 전으로 복원하며, 이후 다른 저장이 있으면 덮어쓰지 않습니다. 루틴 실행은 각각의 실제 동작을 기록합니다. 되돌릴 수 없는 문서 입력·웹 동작은 이유를 안내하며 앞선 동작으로 건너뛰지 않습니다. 문서는 직접 Ctrl+Z를 사용하세요. 음량은 이후 사용자가 바꾸거나 출력 장치가 바뀌면 덮어쓰지 않습니다. 앱 창은 비서가 시작한 프로세스의 새 창을 확인한 경우에만 닫고 저장 확인을 우회하지 않습니다. 기존 창·탭을 재사용하는 앱은 자동 닫기 대상에서 제외됩니다. 다시 시작하면 창 소유권과 동작 기록은 초기화됩니다.

## 설정 파일 보관

설정 화면 맨 아래의 **설정 내보내기**는 마지막으로 저장한 설정을 JSON 파일에 보관합니다. 화면에서 아직 저장하지 않은 편집 내용은 포함하지 않습니다. 기존 내보내기 파일을 바꾸면 그 파일의 `.previous`도 남깁니다.

**설정 가져오기**에서 이 Windows 앱이 내보낸 파일을 고르면 변경 전후가 표시됩니다. ‘확인한 설정 적용’을 누르기 전에는 현재 값을 바꾸지 않습니다. 기본적으로 현재 PC의 AI 연결·Whisper 주소·코딩 폴더와 마이크·목소리·출력 장치·알림 화면을 유지합니다. 해당 항목까지 복원하려면 확인 창에서 선택하세요. 단축키가 다른 앱과 충돌하면 복원이 적용되지 않습니다. 적용 전 설정은 `config.json.backup`에 보관합니다.

파일에는 API 키·로그인 정보·기억·루틴·등록 앱·타이머·진단 기록이 포함되지 않습니다. 호출 이름, 사용자 호칭, 인사말과 웹 주소, 단어 목록, 연결 주소와 프로젝트 경로는 포함될 수 있습니다. macOS 원본의 설정 파일은 이 형식으로 가져올 수 없습니다.

## 음성 인식 조절

| 단계 | 설정 | 초기값 / 의미 |
| --- | --- | --- |
| 마이크 | 입력 마이크 | Windows 기본 장치. 장치명이 같은 경우 MME/WASAPI 항목을 비교 가능 |
| 호출 | 이름 / 호출 방식 | 자비스, 이름 또는 단축키 |
| 호출 감도 | 고급 → 빠른 호출어 감지 / 감지 기준 | 켜짐 / 0.15. 낮을수록 민감 |
| 문장 확정 | 말 끝 대기 시간 | 1.2초, 범위 0.4–3초 |
| 이어 말하기 | 후속 대화 유지 | 30초, 범위 5–120초 |
| 처리 속도 | 고급 → 처리 스레드 | 2개, 범위 1–8개 |
| 정밀 재인식 | Whisper 로컬 서버 주소 | 비어 있음. 선택 사항 |

정밀 재인식은 whisper.cpp의 `/inference`와 호환되는 로컬 HTTP 서버를 따로 실행한 뒤 주소를 입력합니다. `file`, `language=ko`, `response_format=json`을 받고 `{"text":"인식 문장"}`을 반환하는 형식입니다. 연결 실패 시 기본 실시간 결과를 사용합니다. 모델 설치와 인식 정확도 비교는 별도 단계이며, 이 PC에서 정밀 서버 연결까지 검증한 것은 아닙니다.

기본 입력은 sherpa-onnx 한국어 streaming zipformer, 답변 출력은 Windows SAPI의 한국어 음성입니다. 이름 감지·말 끝 대기·정밀 재인식을 분리했으므로 앱 기능을 바꾸지 않고 인식 단계만 조정할 수 있습니다.

음성 인식 정확도 조정은 아직 진행 전입니다. 합성음 검사에서 ‘메모장 열어’가 잘못 인식된 사례도 있으므로, 당장은 텍스트 명령과 단축키를 함께 사용하세요. 키를 놓을 때 인식을 끝내는 동작이 검증됐다는 사실이 사용자 발화 정확도를 뜻하지는 않습니다.

## AI 연결과 저장 위치

- **Claude Code**: 이 PC의 설치와 로그인을 사용합니다. 별도 세션에서 이 앱의 고정 MCP 도구만 호출합니다. 모든 호출은 앱의 명령 검사와 필요한 실행 확인을 거칩니다.
- **Codex**: 이 PC의 Codex CLI 로그인으로 연결합니다. 셸·파일 작업과 사용자 플러그인을 끈 일회성 읽기 전용 세션에서 이 앱의 MCP 도구만 호출합니다. 도구별 호출 허용과 앱의 실행 확인을 함께 적용합니다. Codex 로그인 정보를 복사하거나 저장하지 않습니다. [공식 비대화형 실행 문서](https://learn.chatgpt.com/docs/non-interactive-mode)를 바탕으로 연결했습니다.
- **Ollama**: 로컬 서버와 설치된 모델을 사용합니다. 모델 이름을 비우면 첫 번째 설치 모델을 사용합니다. 이 PC에서 실제 Ollama 추론은 검증하지 않았습니다.
- **Anthropic / OpenAI / Gemini / OpenRouter / Groq API**: 제공자를 선택하고 키 저장 → 모델 목록 조회 → 함수 호출 지원 대화 모델 선택 → 연결 시험 → 설정 저장 순서로 연결합니다. 모델 이름을 직접 입력할 수도 있습니다. 각 제공자의 API 사용료가 적용되며 CLI 구독과 별개일 수 있습니다. 등록한 키로 실제 외부 추론은 아직 검증하지 않았습니다.
- **LM Studio / OpenAI 호환 서버**: 서버 기본 주소(예: `http://127.0.0.1:1234/v1`)와 함수 호출 지원 모델을 선택합니다. 인증이 켜진 서버만 키를 넣습니다. 호환 서버는 HTTPS 또는 루프백 HTTP를 허용합니다. 실제 로컬 모델 추론은 별도 검증이 필요합니다.
- 제공자별 모델과 주소를 따로 기억합니다. API 키는 설정 JSON이 아닌 Windows 자격 증명 관리자에 현재 사용자용 일반 자격 증명으로 저장하며 제공자와 서버 주소별로 분리합니다. 서버 주소를 바꾸면 그 주소의 키를 사용합니다. ‘저장된 키 삭제’는 선택한 제공자·주소의 키만 삭제합니다. 연결 시험은 짧은 인사만 보내고 동작을 실행하지 않습니다.
- 외부 제공자 사용 시 질문, 최근 대화, 저장한 참고 정보와 요청에 필요한 화면 문맥이 선택한 서비스로 전송됩니다. 일반 로컬 명령은 AI를 호출하지 않습니다. 원시 API 오류 본문이나 API 키는 진단 로그에 기록하지 않습니다.
- 입력 음성은 메모리에서 처리하고 WAV 파일로 남기지 않습니다. Whisper 옵션을 켜면 음성 조각을 지정한 로컬 서버로 보냅니다. 외부 답변 음성은 재생을 위해 `voice-temp`에 임시 파일을 만들고 완료·오류·취소 시 삭제합니다. 강제 종료 시 남은 임시 파일은 별도로 정리할 수 있습니다.
- 자유 질문은 선택한 AI로 전달됩니다. Claude/Codex를 사용할 때 질문·최근 대화·저장된 기억 및 사용자가 요청한 화면/선택 문장 내용은 해당 제공자로 전달될 수 있습니다. 일반 앱 실행과 타이머는 AI 연결 없이 처리합니다.
- 설정·루틴·기억·타이머·진단 로그: `%LOCALAPPDATA%\VoiceAssistantWindows`. `config.json`, `personal.json`, `timers.json`은 교체 시 이전 파일의 `.backup`을 남깁니다. `assistant.log`에는 명령·답변이 기록되며 약 2 MB에서 이전 파일로 회전합니다.
- 화면 대화 기록은 현재 실행 동안 유지합니다. `VOICE_ASSISTANT_HOME` 환경변수로 별도 테스트 데이터 폴더를 지정할 수 있습니다.

## 검증과 범위

```powershell
# 실행 중인 앱을 먼저 종료
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify.ps1
# 실제 Claude 연결 검사 포함
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify.ps1 -AI
# 실제 Claude, Codex, 유튜브 검색까지 검사
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify.ps1 -AI -Codex -YouTube
```

결과는 `artifacts/checks.json`에 기록됩니다. `artifacts`, 가상환경, 모델, 빌드 출력은 Git에서 제외합니다. 명령 파싱·범위 검증·루틴/기억 저장·타이머 복원은 자동 검사하고, 실제 창 입력·마이크·단축키·앱 수명은 수동 UI 검사합니다. 마이크가 열렸다는 사실이나 샘플 WAV 인식 성공은 사용자 발음·소음 환경에서의 정확도를 보장하지 않습니다.
